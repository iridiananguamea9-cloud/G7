EXTERNAL-DEPENDENCY: ESS-2003 (Escauriaza-Seregin-Sverak)
INPUT: $C_{L^3}$ PROVEN: $T_*<\infty\implies \limsup\|u\|_3=+\infty$
TARGET: $C_G$: $\exists t_n\uparrow T_*, x_n, r_n\downarrow0: \|u(t_n)\|_{L^3(B(x_n,r_n))}\ge\epsilon_0$

AUDIT:

1. What ESS-2003 actually proves:
If $u$ suitable weak in $R^3\times(-1,0)$ with $\|u\|_{L^\infty_t L^3_x}\le M<\infty$, then regular up to 0. Contrapositive gives $C_{L^3}$.

2. Does ESS imply $C_G$?
ESS gives global criterion, not local ball lower bound with $r_n\to0$.
To get $C_G$ need concentration-compactness: rescale near blow-up, extract profile. If no concentration, scaling limit would be bounded $L^3$ regular, contradicting blow-up. Requires backward uniqueness + profile decomposition, not stated as $C_G$ in ESS.

Thus:
\begin{equation*}
\boxed{\text{ESS-2003 does NOT directly imply $C_G$ as defined}}
\end{equation*}

3. What additional bridge needed?
(i) Local $\epsilon$-regularity: $\|u\|_{L^\infty_t L^3(B_1)}\le \epsilon_*$ implies regularity. This is Kozono-Taniuchi / ESS local version, distinct from global ESS.
(ii) $r_n\downarrow0$ guarantee requires parabolic scaling $r_n\sim\sqrt{T_*-t_n}$.

4. Is $\epsilon_0$ universal?
Universal only if local version holds, not from global ESS constant alone.

5. Extra hypotheses: suitable weak, finite energy, pressure in $L^{3/2}_{loc}$.

STATUS:

$\boxed{C_G^{cond}\text{ NOT DERIVED from ESS-2003 alone}}$

$\boxed{C_G\text{ remains OPEN, requires local epsilon-regularity + concentration}}$

$\boxed{\text{ESS}\implies C_{L^3}\text{ PROVEN, but ESS}\not\implies C_G\text{ directly}}$

Hence $\mathcal{C}_{PROVEN}=\{C_E^{weak},C_{L^3}\}$ untouched.

Next: G-03 for local version.

FORBIDDEN respected: No claim ``ESS implies $C_G$'' without explicit bridge.
